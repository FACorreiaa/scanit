# ScanIt release runbook

**You** = owner (accounts, money, decisions). **Claude** = code and config in this repo.

**Order matters:**

1. TestFlight (internal)
2. Landing page live
3. TestFlight (external, the strangers gate)
4. App Store v1.0
5. Backend as v1.1

v1.0 needs **no backend**: the app is local-first. The backend only adds sign-in, sync and web stats, and per the
owner rules it waits until 10 strangers have used the app (BACKLOG P2 → P4).

## Stage 1: TestFlight, internal (automatic from `main`)

The setup mirrors Norviq:

- **Signing:** fastlane match reads the **same** certificates repo (`FinancePlanner/norviq-certificates`) with the same password. A team has one Apple Distribution certificate, so ScanIt only adds its own profiles to it.
- **Two App Store Connect apps:**
  - **ScanIt** (`com.fernandocorreia.scanit`) for the App Store
  - **ScanIt Beta** (`com.fernandocorreia.scanit.beta`) for TestFlight builds, installable next to the store app
- **Automatic uploads:** `.github/workflows/ios-beta.yml` uploads to ScanIt Beta every time `CI` passes on `main`.

| # | Who | Step |
| --- | --- | --- |
| 1.1 | Claude ✅ | Draft **app icon** done (2026-10-09): viewfinder plus barcode in light, dark and tinted versions, opaque 1024×1024, generated by `tools/make-icon.swift`. **You:** approve it or supply your own. Replacing it means changing three PNGs in `AppIcon.appiconset`. |
| 1.2 | Claude ✅ | `ITSAppUsesNonExemptEncryption = NO` set. The app only uses standard HTTPS, so no export-compliance question on uploads. |
| 1.3 | Claude ✅ | Pipeline in place (2026-10-10):<br>• a `Beta` build configuration (bundle ID `com.fernandocorreia.scanit.beta`, display name "ScanIt Beta")<br>• `scanit/fastlane/` with the `beta` and `seed_signing` lanes<br>• the `Gemfile` from Norviq<br>• the `iOS beta` workflow |
| 1.4 | You | **Register both App IDs.** developer.apple.com → Certificates, Identifiers & Profiles → Identifiers → **+** → App IDs → App. Create:<br>• `com.fernandocorreia.scanit`, description "ScanIt" (it may already exist, because Xcode registered it during the test archive)<br>• `com.fernandocorreia.scanit.beta`, description "ScanIt Beta"<br>Default capabilities are enough; In-App Purchase is on by default. |
| 1.5 | You | **Create the two apps.** App Store Connect → Apps → **+** → New App, twice:<br>• Platform iOS, name **ScanIt**, primary language English (U.K.) or Portuguese, bundle ID `com.fernandocorreia.scanit`, SKU `scanit`, User Access Full.<br>• Platform iOS, name **ScanIt Beta** (if taken, "ScanIt TestFlight"), same language, bundle ID `com.fernandocorreia.scanit.beta`, SKU `scanit-beta`.<br>The beta app is never released, so its name only matters on TestFlight. |
| 1.6 | You | **Add the repo secrets**, with the same values Norviq uses (from your password manager), on `FACorreiaa/scanit`:<br>`gh secret set ASC_KEY_ID -R FACorreiaa/scanit`<br>`gh secret set ASC_ISSUER_ID -R FACorreiaa/scanit`<br>`base64 -i AuthKey_<KEYID>.p8 \| gh secret set ASC_KEY_P8 -R FACorreiaa/scanit`<br>`gh secret set MATCH_PASSWORD -R FACorreiaa/scanit`<br>`printf 'x-access-token:%s' "<PAT>" \| base64 \| gh secret set MATCH_GIT_BASIC_AUTHORIZATION -R FACorreiaa/scanit`<br>The PAT is a fine-grained token, resource owner **FinancePlanner**, repository `norviq-certificates`, permission **Contents: Read and write**. | 1.7 | You | **Seed signing once.** GitHub → Actions → **iOS beta** → Run workflow → lane `seed_signing`. This adds the App Store profiles for both bundle IDs to the match repo, using the existing distribution certificate. |
| 1.8 | You | **First upload.** Actions → **iOS beta** → Run workflow → lane `beta` (or just push to `main`). About 15 minutes later the build appears under App Store Connect → ScanIt Beta → TestFlight. From now on, every push to `main` that passes CI uploads a new build automatically. |
| 1.9 | You | **Internal testers.** ScanIt Beta → TestFlight → Internal Testing → **+** group "Team" → add yourself → turn on **Automatically distribute builds**. Internal testing needs no Apple review. |
| 1.10 | You | Install **TestFlight** from the App Store, then **ScanIt Beta**. Do the first real test: one trip in a real supermarket **in airplane mode** (BACKLOG IOS-013), scanning EAN-13 and EAN-8 barcodes and a QR code (IOS-005). |
| 1.11 | You | Take about 20 shelf-label photos during that trip, for `tools/label-bench` (IOS-006). |

**Cost note.** On a private repo, macOS runner minutes count ×10 against the GitHub plan. Each beta build is about 15 macOS minutes, on top of CI's iOS job. If that adds up, switch the trigger to tags (`v*`) instead of every push. It is a one-line change in `ios-beta.yml`.

**Local alternative** (no CI): `cd scanit && bundle install`, export the same five variables, then `bundle exec fastlane beta`.

### What blocks what

- **Stage 1** needs: the icon (1.1) and the App Store Connect record (1.3).
- **Stage 3** needs: the privacy URL (Stage 2) and PostHog (3.1).
- **Stage 4** needs: the Paid Apps agreement (4.2, can take days, so start early) and the IAP product (4.3).
- **Stage 5** needs: 10 strangers (Stage 3), plus the Apple key and Google client IDs.
