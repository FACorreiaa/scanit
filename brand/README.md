# ScanItNow brand

Source: `source/brand-sheet.png` (owner-supplied, 2026-11-05). Everything else here is generated by the scripts in
`tools/`, so it can be regenerated and never drifts between web and iOS.

Tagline: **Scan smart. Spend with clarity.**

## Assets

| File | What | How it was made |
| --- | --- | --- |
| `logo-mark.svg`, `logo-mark-dark.svg` | The mark: four viewfinder brackets, teal and lime, around a shopping cart. Light uses deeper colours. | Redrawn as exact geometry (`tools/make-mark.swift`) |
| `logo-mark-currentcolor.svg` | Mark whose cart follows the CSS text colour | same |
| `wordmark.svg`, `wordmark-dark.svg`, `wordmark-currentcolor.svg` | "ScanItNow" in Avenir Next Bold, as outlines, "It" in one solid green | `tools/make-wordmark.swift` |
| `png/mascot.png` | The mascot with its scanned package, transparent, 767×641 | Vision subject lifting (`tools/lift-mascot.swift`) |
| `png/logo-mark-1024.png` | Mark, transparent, 1024² | `tools/make-mark.swift` |
| `tools/og.html` | Social card for link previews (`scanit-web/static/og.png`, 1200×630) | Rendered from HTML (command in the file) |

`make-mark.swift` also writes the iOS app icons (light, dark, tinted), the launch-screen mark and the web favicon.

## Rules

- **No effects:** no glow, gradient text or scene backdrops around the logo. The sheet's glow is not part of the mark. Only the brackets carry a gradient.
- **The mascot is for welcome moments**: empty Trip screen, paywall, website hero, social card. It does not go on every
  screen. History and Insights keep plain system symbols. It needs no disc behind it.
- **Lockup:** mark plus wordmark, mark height = 1.2 × wordmark cap height, gap ≈ 0.35 × mark height. Leave clear space
  of half the mark's height on every side.
- **App icon:** the mark alone at 70% of the canvas, on the Night tile in light and dark, grayscale when tinted. Never
  the mascot; it is too detailed at 60 px.
- **Names:** the product is **ScanItNow** in every user-facing string, even though the sheet says "ScanIt", which was
  taken on the App Store. The code, repo and bundle IDs stay `scanit`.

## Regenerate

```sh
swift brand/tools/make-mark.swift .              # marks, app icons, launch mark, favicon
swiftc -O brand/tools/make-wordmark.swift -o /tmp/make-wordmark && /tmp/make-wordmark .
swiftc -O brand/tools/lift-mascot.swift -o /tmp/lift-mascot -framework Vision -framework CoreImage
/tmp/lift-mascot brand/source/brand-sheet.png brand/png/mascot.png
```

Then copy the outputs into `scanit-web/static/brand/` and the asset catalog. Shrink the web mascot with
`sips -Z 720` and encode the AVIF (36 KB vs 564 KB PNG).
